Tiempo

Velocidad Final

Posición en MRUV
\[x = x_0 + v_0t + \frac{1}{2}at^2\]
x = posición final (m) x₀ = posición inicial (m) v₀ = velocidad inicial (m/s) a = aceleración (m/s²) t = tiempo (s)
Ecuación Independiente del Tiempo
\[v_f^2 = v_0^2 + 2ad\]
vf = velocidad final (m/s) v₀ = velocidad inicial (m/s) a = aceleración (m/s²) d = distancia (m)
Útil cuando no conocemos el tiempo
Velocidad Media
\[v_{media} = \frac{v_0 + v_f}{2}\]
vmedia = velocidad promedio (m/s) v₀ = velocidad inicial (m/s) vf = velocidad final (m/s)
Velocidad en Caída Libre
\[v_f = v_0 + gt\]
vf = velocidad final (m/s) v₀ = velocidad inicial (m/s) g = gravedad (9.8 m/s²) t = tiempo (s)
Usar (+) si cae, (-) si sube
Altura en Caída Libre
\[h = h_0 + v_0t + \frac{1}{2}gt^2\]
h = altura final (m) h₀ = altura inicial (m) v₀ = velocidad inicial (m/s) g = gravedad (9.8 m/s²) t = tiempo (s)
Velocidad sin Tiempo
\[v_f^2 = v_0^2 + 2gh\]
vf = velocidad final (m/s) v₀ = velocidad inicial (m/s) g = gravedad (9.8 m/s²) h = altura (m)
Tiempo de Vuelo
\[t_{vuelo} = \frac{2v_0}{g}\]
tvuelo = tiempo total en el aire (s) v₀ = velocidad inicial hacia arriba (m/s) g = gravedad (9.8 m/s²)
Componentes de Velocidad
\[v_x = v_0 \cos(\theta)\] \[v_y = v_0 \sin(\theta) - gt\]
vx = velocidad horizontal (constante) vy = velocidad vertical (variable) v₀ = velocidad inicial (m/s) θ = ángulo de lanzamiento g = gravedad (9.8 m/s²)
Posición en X y Y
\[x = v_0 \cos(\theta) \cdot t\] \[y = v_0 \sin(\theta) \cdot t - \frac{1}{2}gt^2\]
x = distancia horizontal (m) y = altura (m) t = tiempo (s)
Alcance Máximo
\[R = \frac{v_0^2 \sin(2\theta)}{g}\]
R = alcance horizontal máximo (m) v₀ = velocidad inicial (m/s) θ = ángulo de lanzamiento g = gravedad (9.8 m/s²)
Alcance máximo cuando θ = 45°
Altura Máxima
\[h_{max} = \frac{v_0^2 \sin^2(\theta)}{2g}\]
hmax = altura máxima (m) v₀ = velocidad inicial (m/s) θ = ángulo de lanzamiento g = gravedad (9.8 m/s²)
Velocidad Angular
\[\omega = \frac{2\pi}{T} = 2\pi f\]
ω = velocidad angular (rad/s) T = periodo (s) f = frecuencia (Hz)
Periodo y Frecuencia
\[T = \frac{1}{f}\] \[f = \frac{1}{T}\]
T = periodo (tiempo de 1 vuelta) (s) f = frecuencia (vueltas/segundo) (Hz)
Velocidad Lineal
\[v = \omega r = \frac{2\pi r}{T}\]
v = velocidad lineal o tangencial (m/s) ω = velocidad angular (rad/s) r = radio (m) T = periodo (s)
Aceleración Centrípeta
\[a_c = \frac{v^2}{r} = \omega^2 r\]
ac = aceleración centrípeta (m/s²) v = velocidad lineal (m/s) ω = velocidad angular (rad/s) r = radio (m)
Apunta hacia el centro del círculo
Fuerza Centrípeta
\[F_c = m \frac{v^2}{r} = m\omega^2 r\]
Fc = fuerza centrípeta (N) m = masa (kg) v = velocidad (m/s) r = radio (m)
Desplazamiento Angular
\[\theta = \omega t\] \[s = \theta r\]

Usar (+) acelerado, (-) retardado
Desplazamiento Angular
\[\theta = \omega_0 t + \frac{1}{2}\alpha t^2\]
θ = ángulo recorrido (rad) ω₀ = velocidad angular inicial (rad/s) α = aceleración angular (rad/s²) t = tiempo (s)

Velocidad Lineal
\[v_f = v_0 + at\] \[v = \omega r\]
v = velocidad tangencial (m/s) at = aceleración tangencial = αr (m/s²) ω = velocidad angular (rad/s) r = radio (m)
Aceleraciones
\[a_t = \alpha r\] \[a_c = \omega^2 r\] \[a_{total} = \sqrt{a_t^2 + a_c^2}\]
at = aceleración tangencial (m/s²) ac = aceleración centrípeta (m/s²) atotal = aceleración total (m/s²)
Segunda Ley de Newton
\[F = ma\] \[\sum F = ma\]
F = fuerza (N = kg·m/s²) m = masa (kg) a = aceleración (m/s²)
La fuerza resultante determina la aceleración
Peso
\[W = mg\]
W = peso (N) m = masa (kg) g = gravedad (9.8 m/s²)
Fuerza de Fricción
\[f = \mu N\]
f = fuerza de fricción (N) μ = coeficiente de fricción (sin unidades) N = fuerza normal (N)
μestático > μcinético
Torque (Momento)
\[\tau = F \cdot d\] \[\tau = F \cdot L \cdot \sin(\theta)\]
τ = torque (N·m) F = fuerza aplicada (N) d = distancia perpendicular (m) L = brazo de palanca (m) θ = ángulo entre F y L
Trabajo Mecánico
\[W = F \cdot d \cdot \cos(\theta)\]
W = trabajo (J = N·m) F = fuerza (N) d = desplazamiento (m) θ = ángulo entre F y d
Potencia
\[P = \frac{W}{t} = F \cdot v\]
P = potencia (W = J/s) W = trabajo (J) t = tiempo (s) F = fuerza (N) v = velocidad (m/s)
Energía Cinética
\[E_c = \frac{1}{2}mv^2\]
Ec = energía cinética (J) m = masa (kg) v = velocidad (m/s)
Energía Potencial Gravitatoria
\[E_p = mgh\]
Ep = energía potencial (J) m = masa (kg) g = gravedad (9.8 m/s²) h = altura (m)
Energía Potencial Elástica
\[E_{pe} = \frac{1}{2}kx^2\]
Epe = energía potencial elástica (J) k = constante elástica (N/m) x = deformación (m)
Trabajo y Energía
\[W = \Delta E_c = E_{c2} - E_{c1}\]
W = trabajo realizado (J) ΔEc = cambio en energía cinética (J)
El trabajo neto cambia la energía cinética
Energía Mecánica
\[E_M = E_c + E_p\]
EM = energía mecánica total (J) Ec = energía cinética (J) Ep = energía potencial (J)
Conservación de la Energía
\[E_{CA} + E_{PA} = E_{CB} + E_{PB}\] \[E_{MA} = E_{MB}\]
La energía mecánica total se conserva (si no hay fricción ni fuerzas externas)
Principio fundamental: La energía no se crea ni se destruye, solo se transforma
